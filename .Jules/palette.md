## 2026-03-02 - Added Accessibility to ChatbotWidget\n**Learning:** Interactive components like chat widgets often rely on placeholder text and visual toggle states, which are insufficient for screen readers. Inputs need explicit `aria-label`s if lacking associated `<label>` elements, and toggle buttons need `aria-expanded` and `aria-controls` linked to the widget container's `id` to announce state and relationships properly.\n**Action:** Always verify interactive widgets (FABs, popups) implement complete ARIA relationships (controls/expanded) and that all inputs have accessible names independent of visual placeholders.
